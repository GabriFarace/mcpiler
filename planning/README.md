# Planning and AI-Assisted Development Artifacts

This folder is the system of record for planning and AI-development
evidence produced during the assessment.

Expected sections:

- `00-project-brief.md` — product brief
- `01-problem-framing.md` — clarified problem/hypothesis
- `02-scope.md` — MUST / STRETCH / EXCLUDED
- `specs/` — approved implementation spec
- `tickets/` — vertical implementation tickets
- `decisions/` — architecture decision records
- `research/` — focused implementation research
- `experiments/` — optional throwaway experiments
- `handoffs/` — agent handoff artifacts
- `ai-sessions/` — session index and sanitized exports
- `tradeoffs.md` — actual trade-off ledger
- `agent-mistakes.md` — genuine AI mistakes/corrections
- `final-retrospective.md` — final assessment reflection

Do not create placeholder content merely to fill these files.
Artifacts should reflect work that actually happened.
